**Run parallel workers in batches by priority, and have each commit as it goes: a usage limit stops them all at once.**

On 12 and 13 November 2026, nine and then eight workers running together hit the account's five-hour limit and all
stopped mid-task, twice. Nothing was lost (their worktrees and commits survive, and each can be resumed), but
eight half-finished tasks are worth less than four finished ones. Start the most valuable three or four, let them
finish, then the next. Tell each worker to commit each finished piece. Studies that only read should return their
report as text: a worker may be refused permission to write a report file.
