# wts-core

The shared foundation for the [Where They Stand](https://wheretheystand.uk) sites: one package for the parts the
sites have in common, so that a fix is made once and every site is held to the same checks.

**In design: no package code yet.** The design is written first, for the owner's review.

| Read | For |
|---|---|
| [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) | The design. Its first page is the summary for the owner: the eight decisions to check first |
| [`docs/adr/`](docs/adr/) | Twelve short decision records, each with the alternatives weighed |
| [`docs/MIGRATION.md`](docs/MIGRATION.md) | For each site and each shared module: what replaces it, any difference in behaviour, and how sameness will be proved |
| [`docs/API-SKETCH.md`](docs/API-SKETCH.md) | The public interface, name by name |
| [`docs/study/`](docs/study/) | The line-by-line comparison of the four sites' copies that the design rests on |
| [`docs/PHASE-0.md`](docs/PHASE-0.md) | What was checked before any design |
| [`docs/PROGRESS.md`](docs/PROGRESS.md), [`docs/NOTES/`](docs/NOTES/) | Where the work stands, and lessons learned, for whoever picks it up next |

The brief this answers is `plans/family/wts-core-brief.md` in the charity's repository.
